# Comercialización de ELI-LUMINARIA

Material para vender el software como **licencia de uso con suscripción**, con una instalación por cliente en tus cuentas.
Los documentos legales son **borradores para que los revise un abogado colombiano**; no son asesoría legal ni tributaria.

| Documento | Para qué sirve |
|---|---|
| [modelo-comercial.md](modelo-comercial.md) | Cómo vender, cobrar, entregar y mantener el control si no pagan |
| [instalacion-cliente.md](instalacion-cliente.md) | Cómo instalar un cliente nuevo y cómo renovar o suspender su licencia |
| [checklist-lanzamiento.md](checklist-lanzamiento.md) | Lo que hay que resolver antes del primer cliente (proveedores de pago, pruebas, soporte) |
| [contrato-licencia-modelo.md](contrato-licencia-modelo.md) | Borrador del contrato de licencia y servicio |
| [politica-datos-modelo.md](politica-datos-modelo.md) | Borrador de la política de tratamiento de datos personales y de la autorización de los técnicos |
| [manual-administrador.md](manual-administrador.md) | Manual para el administrador del cliente |
| [manual-tecnico.md](manual-tecnico.md) | Guía de una página para el técnico de campo |
